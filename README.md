# dotfiles

The Mac setup installs fzf and bat and loads `fzf/config.zsh` in Zsh.
Run `fzf`, select a file, and press Enter to read it with syntax highlighting
in bat/less, matching Yazi. Press `q` to return to fzf and Escape to exit.
To install this setup separately, run `./fzf/setup.sh` and start a new shell.
